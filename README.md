One sentence, up to 200 characters, on the best advice I ever received — a make.fun bounty entry.

## The entry

> My grandmother said, 'Don't marry a man who is rude to waiters,' and I have never once regretted listening.

## Why this line

My grandmother gave me a test I could run in one meal: how a person treats someone who cannot do anything for them. It is specific (waiters, not "be kind"), earned (a lifetime of never regretting it), and true far beyond the moment it was said. It sounds like a real person recalling a real moment — not a slogan, not a fortune cookie.

## How it works

`main.py` (Python 3, standard library only) writes the sentence to `/output/entry.txt`. A `validate()` gate mirrors the bounty gate before writing: 1–200 characters, not only white space, a single sentence. After writing, it reads the file back and confirms it is byte-identical to the entry.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
